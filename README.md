# CPSC 223P - Final Lab Assignment: Social Media

# Assignment Objective
For this assignment, we created an in-terminal social media application that allows users to create and manage accounts, communicate with other users, and interact through basic social networking features.

## REQUIRED FEATURES

### Account Management
- Create a new account
- Login and logout
- Change account password
- Delete an account

### Messaging
- Send a message to another account using their username

## ADDITIONAL FEATURES

### Profile Features
- Update a personal profile bio/status
- View all users' statuses
- View account creation information

### Social Features
- Follow and unfollow other users
- Check the list of users you are following

## Description
This application simulates a simple social media platform directly in the terminal. Users can create accounts, manage their login credentials, send messages, update their profiles, and connect with other users through following and unfollowing. The project demonstrates basic user account handling, terminal-based interaction, and social media-style functionality.
